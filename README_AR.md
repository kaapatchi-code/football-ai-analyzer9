# FOOTBALL AI ANALYZER

موقع ويب لتحليل مباريات كرة القدم بواجهة عربية. يعتمد الربط الحالي على Highlightly Football API، ويبحث عن الفرق ثم يجلب آخر خمس مباريات مكتملة لكل فريق ويحسب مؤشرات النتائج والأهداف ونموذج Poisson مبسطاً عند توفر عينة كافية.

## التشغيل على Windows
1. ثبّت Python 3.10 أو أحدث.
2. فك ضغط المشروع.
3. افتح مجلد المشروع، ثم اكتب `cmd` في شريط عنوان File Explorer واضغط Enter.
4. نفّذ:

```bat
py -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
```

5. افتح `.env` وضع مفتاح Highlightly في `HIGHLIGHTLY_API_KEY`.
6. شغّل:

```bat
python app.py
```

7. افتح `http://127.0.0.1:5000` في Chrome.

يمكنك أيضاً تشغيل `START_WINDOWS.bat`. لا ترسل المفتاح في المحادثات ولا تضعه داخل HTML أو JavaScript أو GitHub؛ ضعه فقط في `.env` محلياً أو في Environment Variables على Render.

## البيانات ومصادرها
- مزود البيانات: Highlightly Football API، عبر `https://soccer.highlightly.net`.
- المصادقة تتم من الخادم باستخدام الترويسة `x-rapidapi-key`.
- آخر خمس مباريات مكتملة لكل فريق هي العينة المستخدمة في هذا الربط الأولي.
- الركنيات والبطاقات وxG تظهر فقط عندما تكون موجودة في إحصائيات المباراة وضمن تغطية الدوري.
- أحداث المباراة تستخدم لاستخراج أهداف الشوط الأول عندما تكون متاحة.
- الإصابات وodds غير مفعّلة في هذه النسخة. خطة Free/Basic قد تخفي بعض النتائج، وodds غير متاحة في الخطة المجانية بحسب وثائق المزود.
- لا يتم تعويض البيانات الناقصة بالتخمين.

## ترشيد استهلاك الحصة
- توجد ذاكرة مؤقتة للفرق ونتائج آخر خمس مباريات وتفاصيل المباريات لتقليل الطلبات المتكررة.
- يضع الخادم حد حماية داخلياً افتراضياً قدره 85 طلباً يومياً؛ يمكن تغييره عبر `API_DAILY_SOFT_LIMIT`.
- التخزين المؤقت الحالي يختفي عند إعادة تشغيل الخادم.

## حدود التحليل
- نموذج Poisson مبسط مبني على متوسط الأهداف في آخر خمس مباريات؛ ليس نموذجاً احترافياً معايراً ولا يستخدم xG كمدخل أساسي.
- لا يثبت التلاعب أو بيع المباريات. أي حركة سوق غير عادية تحتاج مصادر مستقلة وتحقيقاً موثوقاً.
- النسب تقديرية وليست ضماناً للنتائج أو توصية مالية.
